# Wild Wonders

A fun animal encyclopedia for kids.

## Live site

https://pab89154.github.io/Wild-Wonders/

## Local development

```bash
npm run dev
```

Open [http://localhost:5180](http://localhost:5180).

## Content helpers

Python scripts in this repo (`add-*.py`, `gen_*.py`, `*-facts.py`, etc.) and data files (`*.jsonl`, `strong_profiles.json`) are for maintaining animal facts. Run them from this folder when updating content.
